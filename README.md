#E-commerce Sales & Profitability Analysis

Project Overview

This project focuses on analysing e-commerce sales and profitability using Python, SQL, and Power BI. The goal is to identify sales trends, evaluate business performance, understand discount impact on profitability, and generate actionable business insights.

Tools & Technologies

* Python
* Pandas
* NumPy
* SQL
* SQLite
* Power BI
* Matplotlib

Project Workflow

1. Data Collection: Collected the Superstore sales dataset.
2. Data Cleaning: Cleaned and processed the dataset using Python and Pandas.
3. SQL Analysis: Used SQL queries to analyse sales, profit, customers, products, and regional performance.
4. Exploratory Data Analysis: Used Python, Pandas, NumPy, and Matplotlib to identify trends and patterns.
5. Visualization: Building an interactive Power BI dashboard to present key business insights.

Key Business Insights

* Analysed total sales and profitability.
* Identified top-performing products and regions.
* Investigated the relationship between discounts and profit.
* Examined monthly sales trends.
* Identified regions experiencing profitability challenges.

Repository Contents

* Superstore_Clean.csv – Cleaned sales dataset.
* analysis_queries.sql – SQL analysis queries.
* Python scripts for data cleaning, database creation, data profiling, SQL execution, and analysis.

Project Status

Power BI dashboard development and final documentation are currently in progress.

Objective

To demonstrate practical data analytics skills through data cleaning, SQL querying, exploratory analysis, business insights, and data visualization.
